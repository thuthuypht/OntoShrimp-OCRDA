# Locked Dataset 3 policy

Dataset 3 is the final external Vietnam-curated test set. It MUST NOT be attached, read, evaluated, used for checkpoint/seed selection, or used for any hyperparameter change during this package. The Kaggle runner actively aborts if it detects characteristic Dataset-3 input names. Only after all frozen baseline/ablation experiments are complete and the analysis plan is locked should Dataset 3 be opened for final external evaluation.
